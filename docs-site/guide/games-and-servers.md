# Games and servers

Open **Tools > Game Library** to browse favorites, recent games, and saved private servers. Choose a game or server, select accounts or a group, and select **Launch**.

To choose a game, select **Choose Game**, paste a Roblox game link or enter its Place ID, and select **Find Game**. Select **Choose** on the result. A Place ID is the number in a Roblox game link.

Games appear under **Recent and Favorite Games** after you launch them. Use the star next to a saved game to add or remove it from favorites. You can also search this list by name or Place ID.

## Choose where to join

Select the current server choice, such as **Let Roblox choose**, to open the server menu. You can choose:

- **Let Roblox choose:** Roblox selects a server for the game.
- **Browse public servers:** Pick from available public servers. The list shows player counts and ping when Roblox provides it.
- **Join a player:** Search for a player whose current game and server are visible on Roblox.
- **Private servers:** Choose a saved private server or add a link.
- **Servers used by running accounts:** If a running account is in a verified public server, you can select its server here. The app checks that the server is still public before using it.
- **Enter a Job ID:** Enter the identifier for a running public server. A Job ID stops working when that server closes.

When you launch several accounts, you can only select a public server with enough open spaces for all of them. Use **Refresh Server List** or **Load More Servers** to look for other servers. A server can fill up or close before your accounts join. Roblox also checks whether each account has access.

## Save a private server

1. Choose a game, select the current server choice, and open **Private servers**.
2. Enter a name and a complete Roblox private server link.
3. Select **Save and Use Private Server**.

You can use a Roblox share link or an older private-server game link. The app checks share links with a saved account. When you launch, Roblox checks access for each account. Anyone with the link may be able to join the server. Removing the saved link only removes it from this Mac and does not change the server on Roblox.

## Join a friend

Select **Find Players** in the toolbar, or open **Tools > Joinable Players**.

Choose which saved accounts to check and select **Refresh**. Select a friend, then choose the accounts to launch under **Accounts to Launch**. Select **Check Selected Accounts** to see their status.

To use **Join Friend** or **Join Accounts with Friend Relay**, select at least one account listed under **Visible to these accounts**. That account starts first. For a relay, the manager then tries to bring the other selected accounts into the server through confirmed friends. If the app cannot confirm the server, you can try the selected accounts or open the friend’s profile. Roblox may reject accounts that cannot access the server.

The account list shows whether each account is ready, signed out, already running, or unable to join. If the status is unknown, try **Check Selected Accounts** again.
