# Launch settings and windows

Set your usual graphics, sound, and window layout in **Launch Defaults**. To save a particular group of accounts and a game, create a **Launch Set**.

## Set graphics and sound

Open **Tools > Launch Defaults**. Choose a graphics mode, quality, or volume. **Leave Unchanged** keeps the account's current Roblox setting. The manager writes launch settings in each account's own folder.

## Arrange windows

1. Open **Tools > Launch Defaults**.
2. If window control is not enabled, select **Open Accessibility Settings** and allow Roblox Account Manager to control windows. Return to the manager and select **Check Again**.
3. Choose **Tile Windows** to see profiles together or **Full Screen Separately** to give each profile its own desktop. To place a window yourself, select a profile and choose an area on a display.

Tiling fits up to four profiles on each display around the menu bar and Dock. If Roblox opens in full screen, the manager exits full screen before tiling. When launching several accounts, you can choose a layout for that launch.

## Save a Launch Set

1. Open **Tools > Launch Sets** and select **New Launch Set**.
2. Enter a name and select accounts or groups.
3. Choose a shared game and server or set a game for each account in **Per-Account Options**.
4. Select **Save Changes**. To start it, select **Run Launch Set** or double-click the saved set.

A set can use your saved window layout or a layout of its own. It includes the current members of any groups you select. When you add a group, the app also selects its current members individually. If you later remove someone from the group, check whether they are still selected in the set.

You can also select **Save as Launch Set** in the batch screen. Pin a set to run it from the Accounts sidebar. A set that uses a public server opens the server list for its saved game each time.

Use **Per-Account Options** to pick a game, select a saved private server, or change graphics and sound for each account. You can leave **Shared Game** blank when every selected account has a game. **Choose a player** requires every account to use the shared game.

The manager skips accounts that are already running. If some accounts cannot start, review the results before you launch the ready accounts. This also applies to **Open Roblox Apps**. To remove a set, right-click it and select **Delete**.

## Resume a session or save a layout

Open **Tools > Running Accounts** and select **Review Last Session**. Choose the accounts to reopen. You can let Roblox choose another public server if the previous server is unavailable.

Arrange your open Roblox windows, then select **Save Current Window Layout**. Use **Apply** next to a layout to move the running windows. A saved layout uses window positions within each display. Connect the displays it uses before applying it.

## About multiple Roblox copies

The recommended method creates an unchanged copy of the installed Roblox app for each account. The manager checks the copy before launch. The optional advanced fallback modifies copies. Roblox may detect modified clients and restrict accounts that use them. The manager does not enable that fallback by itself.
