# Launch settings and windows

Set your usual graphics, sound, and window layout in **Launch Defaults**. To save a particular group of accounts and a game, create a **Launch Set**.

## Set graphics and sound

Open **Tools > Launch Defaults**. Choose a graphics mode and, if needed, a quality level. You can also choose a volume level. **Leave Unchanged** keeps the value already saved in Roblox. These settings apply before each Roblox launch.

## Arrange windows

1. Open **Tools > Launch Defaults**.
2. If window control is not enabled, select **Open Accessibility Settings** and allow Roblox Account Manager to control windows. Return to the manager and select **Check Again**.
3. Choose **Arrange Automatically** or **Full Screen All** to place all saved profiles. For individual placement, select a profile and choose an area on a display.

Automatic arrangement fits up to four profiles on each display. Windowed layouts fit around the menu bar, Dock, and camera housing. **Full Screen All** gives each profile its own full-screen macOS Space. The manager applies saved placements after Roblox launches. When launching several accounts, you can set an arrangement for that launch without changing your saved layout.

## Save a Launch Set

1. Open **Tools > Launch Sets** and select **New Launch Set**.
2. Enter a name, then choose a game and server.
3. Select accounts or groups. You can also set graphics, sound, and window positions for this set.
4. Select **Save Changes**. To start it, select **Run Launch Set** or double-click the saved set.

A set can use your saved window layout or a layout of its own. It includes the current members of any groups you select. When you add a group, the app also selects its current members individually. If you later remove someone from the group, check whether they are still selected in the set.

**Browse public servers when run** and **Choose a player when run** do not start the game immediately. The manager selects the set's accounts and asks you to choose a server or player. It skips accounts that are already running. To delete a saved set, right-click it in the list and select **Delete**.

## About multiple Roblox copies

The recommended method creates an unchanged copy of the installed Roblox app for each account. The manager checks the copy before launch. The optional advanced fallback modifies copies. Roblox may detect modified clients and restrict accounts that use them. The manager does not enable that fallback by itself.
