# Backup and privacy

Open **Tools > Diagnostics and Backup** to save or restore account details and run a local check.

## What a backup contains

A normal backup contains account details, groups, recent games, favorites, and Launch Sets. It does **not** contain Roblox sign-ins, profile notes, or private server links.

To include private links saved in account settings or Launch Sets, select **Export with Private Links…** and confirm. Anyone with a private link may be able to join its server, so share the backup only with someone you trust. The backup does not include the saved private-server list. You may need to add those servers again.

In a normal backup, a Launch Set that used a private link is saved with **Let Roblox choose** instead. Check its server choice after importing.

## Export a backup

Select **Export Backup** and choose where to save the file.

## Import a backup

Select **Import Backup** and choose your backup file. The app tells you when the import is complete.

Import adds the backup to the data already on your Mac. It replaces details for matching accounts and Launch Sets and adds any new accounts as signed out. Your existing sign-ins and notes stay in Keychain. Check your accounts and Launch Sets after importing.

On a new Mac, select each imported account, choose **Check Account**, then select **Sign In Again** if the account is signed out. Add any profile notes you want to keep. The maximum backup size is 10 MB.

If the app reports that a saved file and its backup are unreadable, it pauses saves that depend on those files. Recover the named files, then reopen the app.

## Share a diagnostic report

Select **Run Check**, then **Export Redacted Report**. The report checks Roblox, app copies, storage, saved sign-ins, and Roblox services. The report excludes Roblox sign-ins, launch tickets, and private server links. Review it before sharing.
