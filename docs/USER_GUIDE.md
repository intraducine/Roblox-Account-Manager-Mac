# User guide

## Install and update

1. Download the ZIP from the [latest release](https://github.com/intraducine/Roblox-Account-Manager-Mac/releases/latest).
2. Extract it and move the app to Applications.

If macOS blocks the app, open **System Settings > Privacy & Security > Open Anyway**. The app is not Apple-notarized. Stop if macOS reports that the download is damaged or harmful.

For updates, choose **Roblox Account Manager > Check for Updates**. If needed, replace the app with the release ZIP. Your saved accounts stay available.

## Accounts and games

Select **Add Account**, sign in, and save. Select accounts, choose a game, and select **Launch Game** or **Launch Accounts**. Use **Open Roblox App** to open Roblox without joining a game.

Sign-ins and notes stay in Keychain. Removing an account deletes its saved sign-in and note. Keep session values private.

## Layouts and shortcuts

- **Launch Defaults:** Set graphics, sound, and window positions. Window placement requires Accessibility permission.
- **Launch Sets:** Save accounts, a game, server, and launch settings.
- **Find Players:** Select a friend and accounts, including one under **Visible To**, then start the relay.
- **Account website:** Right-click an account to open Roblox as that account.

## Roblox closes at once

Update the manager, select **Stop All**, and retry. If Roblox updates, let it finish, quit Roblox, and retry. Keep your saved accounts.

For help, open **Tools > Diagnostics and Backup**, run a check, and send feedback with an **Export Redacted Report**. Keep session values, private-server links, and unreviewed logs private.

Normal backups exclude sessions, notes, and private links. **Export with Private Links** includes private links; protect that backup like a password. The optional **Advanced fallback** modifies Roblox copies and can lead to account restrictions.
