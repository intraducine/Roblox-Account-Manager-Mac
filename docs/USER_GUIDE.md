# User guide

## Install and update

1. Download the ZIP from the [latest release](https://github.com/intraducine/Roblox-Account-Manager-Mac/releases/latest).
2. Extract it and move the app to Applications.

If macOS blocks the app because it is not notarized by Apple, open **System Settings > Privacy & Security** and select **Open Anyway**. If macOS says the app is damaged, download it again from the latest release and replace your copy. If the warning persists or macOS says the app is harmful, do not open it; report the warning on GitHub.

For updates, choose **Roblox Account Manager > Check for Updates**. If needed, replace the app with the release ZIP. Your saved accounts stay available.

## Accounts and games

Select **Add Account**, sign in, and save. Select accounts, choose a game, and select **Launch Game** or **Launch Accounts**. Use **Open Roblox App** to open Roblox without joining a game.

Sign-ins and notes stay in Keychain. Removing an account deletes its saved sign-in and note.

## Layouts and shortcuts

- **Launch Defaults:** Set graphics, sound, and window positions. Window placement requires Accessibility permission.
- **Launch Sets:** Save or pin a batch. Choose a shared game or set a game for each account in **Per-Account Options**.
- **Game Library:** Open it from **Tools**. Choose a favorite, recent game, or private server, then select accounts or a group.
- **Running Accounts:** Switch to a client, review the last session, or save and apply window layouts.
- **Find Players:** Select a friend and accounts, including one under **Visible To**, then start the relay.
- **Account website:** Right-click an account to open Roblox as that account.

## Roblox closes at once

If Roblox updates, let it finish and quit Roblox. Select **Check Roblox Version**, then **Retry Launch**.

If some accounts cannot start, review the account results and select **Launch Ready Accounts**.

The three-dot **More** menu also lists the Tools commands. For help, open **Diagnostics and Backup**, run a check, and select **Export Redacted Report**. You can include the report with your feedback.

Normal backups exclude sessions, notes, and private links. **Export with Private Links** includes private links; protect that backup like a password. The optional **Advanced fallback** modifies Roblox copies and can lead to account restrictions.
